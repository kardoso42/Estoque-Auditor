# Back-office V51

Área administrativa do Smart Estoque.

Responsabilidades previstas:
- Dashboard
- Gestão do catálogo
- Importação de planilhas
- Auditoria
- Divergências
- Relatórios e exportações
- Usuários e permissões
- Configurações administrativas

O Back-office será desenvolvido isoladamente e não terá acesso aos dados de produção enquanto estiver em ambiente de teste.
